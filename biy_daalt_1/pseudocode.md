# APL121 — Бие даалт №1

## Сэдэв №12: Тооны шидэт хүснэгт

### 1. Програмын тухай

Энэхүү програм нь хэрэглэгчээс гурван тоо (`a`, `b`, `c`) болон хүснэгт гаргах нэг тоо (`n`) авна. Оруулсан тоонууд эерэг, 5 оронтой тооноос хэтрэхгүй байх ёстой.

Програм дараах үйлдлүүдийг гүйцэтгэнэ:

- Оруулсан тоог шалгаж, буруу утга оруулсан бол дахин оруулахыг хүснэ.
- Тоо тэгш эсвэл сондгой эсэхийг тодорхойлно.
- Тооны цифрүүдийн нийлбэр болон урвуу дарааллыг олно.
- `n` тооны үржүүлэх хүснэгтийг 1-ээс 10 хүртэл хэвлэнэ.
- `a`, `b`, `c` тоонуудын цифрүүдийн нийлбэрийг харьцуулж, хамгийн их нийлбэртэй тоог олно.

### 2. Ашигласан технологи

- **Програмчлалын хэл:** C
- **Flowchart боловсруулах програм:** Flowgorithm
- **Хөрвүүлэгч:** GCC

### 3. Програмыг ажиллуулах заавар

`main.c` файл байгаа хавтас руу терминалаар орж дараах командыг ажиллуулна.

```bash
gcc main.c -o main
```

Дараа нь програмыг ажиллуулна.

**Windows:**
```bash
main.exe
```

**Linux / macOS:**
```bash
./main
```

### 4. Оролтын дүрэм

- Оруулах тоо нь бүхэл тоо байна.
- Зөвшөөрөгдөх утга: `1`-ээс `99999` хүртэл.
- `0`, сөрөг тоо болон 5 оронтой тооноос их утгыг зөвшөөрөхгүй.
- Буруу утга оруулсан тохиолдолд програм дахин утга оруулахыг хүснэ.

### 7. Програмын үндсэн функцууд

- `inputcheck()` — хэрэглэгчийн оруулсан тоо зөв эсэхийг шалгана.
- `numbersum()` — тооны цифрүүдийн нийлбэр болон урвуу дарааллыг тооцоолно.
- `main()` — оролтуудыг авч, тоонуудыг боловсруулан үржүүлэх хүснэгт болон хамгийн их цифрийн нийлбэрийг хэвлэнэ.
