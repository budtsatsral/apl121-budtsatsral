## Test 1: Buruu orolt
Orolt: a = -1, daraa ni 123; b = 12345; c = 4444; n = 9999

**Huleegdej bui ur dun:**

- 123 ni sondgoi too.
- 12345 ni sondgoi too.
- 4444 ni tegsh too.
- 9999 ni sondgoi too.
- 9999 toony tsifriin niilber = 36.
- 9999 toony urvuu too = 9999.
- Urjuuleh husnegt 1-10 hurtel hevlegdene.
