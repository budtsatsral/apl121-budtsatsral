
# APL121 — Бие даалт №1
## Сэдэв 12: Тооны шидэт хүснэгт

Энэ програм нь хэрэглэгчээс тоонууд авч, тэгш сондгой эсэхийг шалгана. Мөн цифрүүдийн нийлбэр, урвуу тоог олж, оруулсан тооны үржүүлэх хүснэгтийг хэвлэнэ. Эцэст нь цифрүүдийн нийлбэрийг харьцуулж хамгийн ихийг нь олно.

### Програмыг ажиллуулах

```bash
gcc main.c -o main
```

Windows дээр `main.exe`, Linux дээр `./main` гэж ажиллуулна.

### Оролтын дүрэм

1–99999 хүртэлх эерэг бүхэл тоо оруулна. Буруу утга оруулбал дахин оруулах шаардлагатай.

### Ашигласан файлууд

- `main.c` — програмын код
- `quest.fprg` — Flowgorithm блок схем
- `flowchart.png` — блок схемийн зураг
- `pseudocode.md` — алгоритмын тайлбар
- `tests.md` — туршилтын үр дүн

### Дүгнэлт

Энэхүү бие даалтаар хэрэглэгчийн оролтыг шалгах, нөхцөлт оператор, давталт, функц ашиглах, цифрүүдийн нийлбэр болон урвуу дарааллыг олох, үржүүлэх хүснэгт хэвлэх зэрэг програмчлалын үндсэн ойлголтуудыг хэрэгжүүлсэн.



Блок схемээ зурахдаа AI тусламж авч, алхам дарааллыг нь ойлгож Flowgorithm дээр боловсруулсан. Мөн блок схемээ даалгаврын шаардлагад нийцүүлэхийн тулд AI ашиглан зөвлөгөө авсан.
